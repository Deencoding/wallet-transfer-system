# Ledger discrepancy

1. Stop mutations for the affected wallet if continued operation could compound risk.
2. Preserve database and application evidence.
3. Run financial reconciliation and inspect expected/actual snapshots.
4. Never update or delete journal entries.
5. Use the audited projection rebuild only for a pure wallet projection mismatch.
6. Use an approved compensating journal/reversal for genuine financial correction.
7. Rerun reconciliation and document resolution.
